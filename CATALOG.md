# Game catalog

Every game and language you can pass to `data-dysc-game` / `game` and `data-lang` / `lang`. Generated from the live site list: 5 games in 6 languages, 30 combinations, updated 2026-10-18; machine-readable: [`catalog.json`](catalog.json) or <https://docs.dyscalculia.io/embed-catalog.json>.

These are **practice games**: no score, no result, not a test. English is the default language (`data-lang` can be left out).

| Language | `lang` | Credit line written under the game |
|---|---|---|
| English | `en` | Free number games by Dyscalculia.io |
| German | `de` | Kostenlose Zahlenspiele von Dyscalculia.io |
| French | `fr` | Jeux de nombres gratuits de Dyscalculia.io |

| Dutch | `nl` | Gratis getallenspelletjes van Dyscalculia.io |
